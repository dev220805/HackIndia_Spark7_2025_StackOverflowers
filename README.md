# 🤖 Smart Donation System

**Smart Donation System** is an AI-powered web application that bridges the gap between donors and trusted NGOs or individuals in need. It leverages artificial intelligence to make donations more impactful, secure, and personalized.

## 🚀 Features

- 🔍 **AI-Based Matching**: Recommends causes based on donor preferences and donation history.
- 🔐 **Fraud Detection**: Detects suspicious activity or fake NGOs using anomaly detection.
- 📊 **Impact Visualization**: Donors receive updates on how their contributions are used.
- 🤖 **Chatbot Support**: Helps users navigate the donation process with ease.
- 🧾 **NGO Verification**: Ensures only legitimate and verified organizations receive donations.
